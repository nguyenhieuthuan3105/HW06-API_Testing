# Thư mục Bằng chứng Thực thi (Anti-AI-Cheat Evidences)

Thư mục này dùng để lưu trữ các hình ảnh chụp màn hình chứng minh quá trình thực thi kiểm thử thực tế trên máy sinh viên:

1. `prerequest_header_console.png`: Ảnh chụp màn hình Postman Console hiển thị rõ ràng header `X-Student-Id: {StudentID}` trong Network Request Headers.
2. `newman_localhost_execution.png`: Ảnh chụp màn hình chạy lệnh Newman trên terminal với target URL là `http://localhost:3000` hoặc `http://127.0.0.1:3000`.
3. `cicd_all_passed.png`: Ảnh chụp màn hình GitHub Actions workflow màu xanh (All Passed).
4. `cicd_one_failed.png`: Ảnh chụp màn hình GitHub Actions workflow màu đỏ (One Failed).
